# لوحة تحكم قسم المتابعة — ARRIVE

لوحة واحدة تجمع 3 لوحات + تبويب «العرض التقديمي». افتح `index.html` (أو انشره على Vercel/GitHub Pages).

| التبويب | الملف | مصدر البيانات |
|---|---|---|
| عدم الإبلاغ / عدم إرسال صورة | `pages/non-reporting.html` | Apps Script الخاص بها (+ Sheets CSV احتياطي) |
| Fleet Validation | `pages/validation.html` | Apps Script الخاص بها (`API_URL` داخل الملف) |
| Control Tower (سابقًا Fleet Support) | `pages/support.html` | Apps Script الخاص بها (`DEFAULT_API_URL`، أو ⚙️ في الواجهة) |
| العرض التقديمي | `pages/presentation.html` | يقرأ من اللوحات الثلاث أعلاه (بدون أرقام ثابتة) |

- كل لوحة محفوظة كما هي بدون تغيير في منطقها أو أرقامها؛ الصفحة الرئيسية تعرضها داخل تبويبات وتحمّل كل لوحة عند أول فتح فقط.
- الرابط المباشر لتبويب: `index.html#overview` (المؤشرات الرئيسية) أو `#reporting` أو `#validation` أو `#support`.
- التبويبات في شريط جانبي، وتبويب «المؤشرات الرئيسية» يجمع كروت المؤشرات الظاهرة حاليًا في كل لوحة (تُقرأ من اللوحات نفسها؛ يتطلب فتح الموقع عبر http وليس ملف محلي).

- التعديل على أي لوحة يتم في ملفها داخل `pages/`. نسخ `validation.html` و`support.html` منسوخة من مستودعي `fleet-validation-dashboard` و`Fleet-new` (الأخير يُبنى من `parts/` بـ `tools/build.py`)؛ أي تحديث هناك يجب نسخ ناتجه هنا.

## العرض التقديمي (`#deck`)

- شرائح بنفس شكل تقرير «Fleet Support Executive Report» (Control Tower ← عدم الإبلاغ ← Validation: تسليم / إلغاءات / تأكيدات).
- كل الأرقام تُحسب من بيانات اللوحات الثلاث عبر جسر قراءة `window.__deck` في كل صفحة (قراءة فقط، لا يغيّر منطق اللوحة). الفلاتر المطبقة داخل اللوحات لا تؤثر على العرض؛ اختيار الشهر من أعلى العرض.
- Control Tower: يستدعي `analytics` من Apps Script لكل شهر (آخر 3 شهور حتى الشهر المختار). مؤشر «الحل والتأكيد» في شريحتي الموظفين وأنواع المشاكل = (تم الحل + تم التأكيد) ÷ الإجمالي كما في التقرير.
- الشرائح التي مصدر بياناتها غير متاح تُخفى تلقائيًا، وتُعاد المحاولة كل 8 ثوانٍ.
- فلاتر متعددة الاختيار (الفرع / الموظف) أعلى العرض: تنطبق على Validation وعدم الإبلاغ وجداول/رسوم الفروع والموظفين؛ إجماليات Control Tower وأنواع المشاكل والفترات لا تتأثر (تأتي من Apps Script بفلتر فرع واحد فقط)، وتُخفى شريحتا النظرة العامة وعدم الإبلاغ الإجمالي أثناء الفلترة لأن أرقامهما غير قابلة للتجزئة.
- شريحة نتائج التحقيق تحتاج `apps-script/validation-Code-gs-inv-patch.md`.
- ملء الشاشة، الأسهم للتنقل، «طباعة / PDF» لتصدير كل الشرائح.
- غير موجود في بيانات اللوحات (لذلك غير مُدرج): نتائج التحقيق التفصيلية (تم التحقيق / مرتجعات / قيد التشغيل)، خصومات المناديب، أسماء مناديب Fake في «لم يتم التأكيد»، وقائمة «المشاكل التي يواجهها القسم».

- تقسيم «حسب الساعة» في Control Tower يحتاج `apps-script/support-hourly-patch.md` (حقل `periods.hourly`).
- فلاتر Validation (الشهر/الفرع/الموظف) متعددة الاختيار.
- «المؤشرات الرئيسية»: ملخص مجمّع Control Tower + Validation مع فلتر الشهر (يقرأ من الجسر `window.__deck` في اللوحتين).
- العرض التقديمي: زر «تنزيل PowerPoint» يولّد ملف .pptx (كل شريحة صورة بنفس التصميم؛ غير قابلة للتحرير النصي) — يحتاج إنترنت لتحميل مكتبتي PptxGenJS وhtml2canvas من cdnjs.
- Control Tower: قائمة التنقل (الملخص التنفيذي / أداء الفروع …) أفقية أعلى الصفحة بدل الشريط الجانبي.
